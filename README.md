# Credit Risk Data Quality Project
## Описание проекта. 
**Проект:** Мониторинг и анализ качества данных и производительности моделей. 

**Роль:** Data Analytics. 

**Бизнес-задача:** Снизить финансовые потери и операционные риски, вызванные малым ухудшением качества данных, что приводило к ошибочным предсказаниям ML-моделей (кредитный скоринг, антифрод и т.п). 

**Технический стек:** Python (pandas, numpy, matplotlib, scikit-learn), SQL (агрегация оконных функций), Juputer Notebook.

## Структура проекта.
- `data/` - Данные (синтетические)
- `notebooks/` - Jupyter ноутбуки с анализом.
- `reports/` - Отчеты и визуализации.
- `src/` - Вспомогательные скрипты.

## Установка.
```bash
pip install -r requirements.txt
```

## Результаты.
***Влияние на бизнес:*** Показано, что 8 из 10 самых критических инцидентов прямо коррелируют с заметным снижением точности (от -1.7% до -20%) основных моделей, что подчеркивает критическую важность системы мониторинга качества данных для бизнеса.
	
***Распределение причин:*** Выявлено, что основной причиной для возникновения инцидентов высокой критичности являются ручной ввод данных (MANUAL_DATA_ENTRY) и повреждения баз данных (DATABASE_CORRUPTION). Это указывает на необходимость усиления автоматизации валидации и улучшения процедур бэкапа.	

***Предотвращения повторения:*** Анализ показал, что повторяющиеся инциденты, как правило, имеют определенные причины и часто связаны с однотипными сбоями, что позволяет разработать точечные решения для их устранения.
